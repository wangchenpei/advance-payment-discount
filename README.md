# 预缴保费计算器

在本地运行：

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址即可。

## 计算规则（与需求一致）

- 名义保费 `T`，分 `n` 年等额缴，每期 `P = T/n`。
- 客户一次性实缴保费 `X`；第 0 时刻先扣 `P`；之后前 `n−2` 个计息年度：每年末先按该年利率滚存一年，再扣 `P`。
- 最后一个计息年度：**只滚存、不再扣** `P`，使期末余额**恰好等于**最后一期 `P`（与「第 4 年底剩余恰为最后一期保费」一致）。
- 共 **`n−1` 个**年利率，在弹窗中按 **百分比** 填写。
- **官方折扣** `d%`（可选，默认 0）：在仅计息模型下的一次性预缴额 `X_{\mathrm{int}}` 基础上，客户实缴 `X = X_{\mathrm{int}} - \frac{d}{100}\cdot\frac{T}{n}`（即每期名义保费 `P=T/n` 的 `d%`）。结果区**年化预缴优惠**仍按 `(T-X_{\mathrm{int}})/T\times n` 取整为百分点；**官方优惠**为 `d%`（取整）；**总保费优惠**元按 `T-X` 取整。
- **年化预缴优惠**与官方折扣分列展示；每期保费、实缴金额、总优惠在结果区按**元取整**；倒推与验算仍用双精度浮点计算。

由此从末态由 `T` 与利率倒推 `X_{\mathrm{int}}` 再扣官方减免得实缴 `X`（正向），或由实缴 `X` 与 `d` 反解 `T`（反向）；逐年验算仍按足额计息账户 `X_{\mathrm{int}}` 推演。

## 构建静态文件

```bash
npm run build
```

产物在 `dist/`，可部署到任意静态站点。

## 部署到 GitHub Pages（远程访问）

1. 在 GitHub 上新建仓库，把本目录推送到该仓库（默认分支为 `main` 或 `master` 均可）。
2. 打开仓库 **Settings → Pages**。
3. **Build and deployment** 里 **Source** 选择 **GitHub Actions**（不要选「Deploy from a branch」的旧方式，否则不会跑本工作流）。
4. 在 **Actions** 里确认工作流 **Deploy GitHub Pages** 已成功执行；完成后 **Settings → Pages** 顶部会显示站点地址，一般为：
   - `https://<你的用户名>.github.io/<仓库名>/`

之后每次推送到 `main` 或 `master`，都会自动重新构建并更新线上页面。

生产构建已配置为 **相对资源路径**（`vite` 的 `base: './'`），子路径部署无需再改仓库名。

### 若 Actions 里构建失败

- 确认仓库根目录即为本项目（含 `package.json`、`index.html`）。
- 在 **Actions** 中点开失败的任务查看日志。
